## The short version

I build tools that make life harder for scammers.

I'm a self-taught developer in Accra, Ghana. I started by watching people around me lose money to phishing links, fake mobile-money messages and cloned login pages, and I got tired of it. So I started building the thing I wanted to exist: **ScamWatch Ghana**, a platform where anyone can check a message, a link or a number before they trust it.

Everything else I ship follows the same instinct. If a surface can be abused, I want to see how, then close it. That's why half of what I build is a product and the other half is the security work that keeps the product honest.

> Built on free tiers, mobile data, and stubbornness.
